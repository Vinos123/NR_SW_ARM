# 第02课：资源网格与索引

建议用时：4–6小时。先修：第1课。每周另留1–2小时复盘。

## 目标与协议定位

用一维连续内存承载二维网格。资源映射使用symbol-major，即先按频率递增填充一个符号，再进入下一个符号。层、天线端口与物理天线不是同一个概念，本课只实现单端口。

精读：**38.211 §4.4.2、§4.4.4**。规范版本见[资料索引](../../docs/references.md)。
先按条款找到输入/输出符号，再看本课接口，不需要顺序通读整本规范。

## 手算与变量

l=2、k=4、72子载波：offset=2×72+4=148。有效l为0..13。

接口：

```cpp
int GridIndex(int symbol, int subcarrier, int tones);
```

比特使用0/1字节，索引从0开始；复数为`std::complex<float>`；LLR正值代表0。
`A/B/K/N/E/G`均以比特计，`Zc`是提升尺寸，RE是复数符号所在的网格位置。

## 构建、运行与预期结果

先按[Windows环境说明](../../docs/windows_setup.md)配置现有工具链。
**在VS Code直接打开本课目录**，选择当前GCC Kit，执行CMake: Configure。
选择Build目标`lesson_02_solution`或`lesson_02_exercise`，再选择相同Launch目标运行或调试。
不需要先构建根工程，不使用“编译当前文件”。

完成Configure后，可在本课目录的PowerShell终端运行（build为实际构建目录）：

```powershell
cmake --build build --target lesson_02_solution lesson_02_exercise
ctest --test-dir build --output-on-failure
.\build\lesson_02_solution.exe
.\build\lesson_02_exercise.exe
```

单配置构建使用上述exe路径；CMake Tools Run/Debug会自动识别其他生成器的实际输出目录。
答案通过时输出`PASS lesson 02`，退出码0。骨架初始输出`NOT IMPLEMENTED`并返回1。
SIMD课未启用或硬件不支持时输出SKIP，返回77。
查看[main.cc](main.cc)的固定输入与断言，不要删除断言来使程序通过。
本课的必要模块见[CMakeLists.txt](CMakeLists.txt)末尾；只编译这些模块及其传递依赖。

## 常见错误与自测

不要把PRB索引直接当作子载波索引；需要乘12。

- 先解释输入输出长度，再单步检查第一个不一致的位置。
- 修改一个边界输入，预测结果后运行；浮点比较使用容差。
- 写三句话：本课解决什么问题、哪个条款决定行为、测试如何证明正确。
