# 随协议实验学习C++

## 第1周：值、引用、容器与构建

`int`保存计数，`float`保存信号幅度，`std::complex<float>`保存I+jQ。
`std::vector<T>`拥有动态数组内存，离开作用域会自动释放，这是RAII。
`const T&`只读引用避免复制；`T&`允许修改原对象。

```cpp
std::vector<float> samples(4, 0.0f);
float& first_sample = samples[0];
first_sample = 1.0f;  // samples[0]也变为1。
```

头文件声明接口，`.cc`定义行为。编译把每个`.cc`变成对象文件，链接把它们及库组合为exe。
CMake描述依赖关系，Ninja执行构建；VS Code/CLion只是调用这条工具链。

## 第2周：位运算与非拥有视图

`^`是异或，`&`是按位与，`>>`是右移。`(value >> i) & 1U`提取第i位。
`uint8_t`在这里存一个逻辑比特，虽然占一个字节；这让索引调试更直观。
`std::span<const uint8_t>`只借用已有比特内存，不分配、不复制，不能比原容器活得更久。

```cpp
Bits bits{0, 1, 1, 0};
std::span<const uint8_t> view(bits);
auto middle = view.subspan(1, 2);  // 借用[1,1]。
```

## 第3周：整数与浮点各司其职

长度、索引、CRC必须使用整数。浮点用于码率、噪声、LLR和复数信号。
正整数向上取整`ceil(a/b)`可写`(a+b-1)/b`；不要先进行整数除法再调用ceil。
`size_t`是无符号类型，`i-1`在i=0时会变成大正数，循环边界须先检查。

`CodingPlan`将A/B/C/Zc/K/N集中存放，使协议中的长度链能够在调试器中观察。
本教程公开这些教学参数，但只应通过`MakeCodingPlan`生成有效计划。

## 第4周：lambda与适配层

编码中的lambda是一个小的局部函数。`[&]`表示借用所在函数的变量，适合局部循环，
不要把它保存到变量生命周期之外。
`std::unique_ptr`独占堆对象的生命周期；LDPC工作缓冲较大，使用堆可避免Windows栈限制。
适配层负责类型、量化、布局转换，不应悄悄改变协议比特。

## 第5–7周：数值约定与程序契约

`std::norm(z)`是|z|²；`std::abs(z)`是|z|。噪声方差是功率，不能混用。
浮点往返通常有舍入误差，使用`abs(actual-expected)<tolerance`。
比特处理则逐比特精确比较。

本工程不用C++异常作为错误处理机制。无效输入调用`Require`，打印原因并以退出码1结束；
适合独立教学程序。生产服务应把用户输入验证和可恢复错误改为显式状态返回。
未完成骨架通过`Fail`明确失败，不能静默返回全0。

## 第8周：数据布局先于指令

QPSK LLR数组交织I/Q，连续float便于向量加载。AVX-512一次16个float，
SVE的元素数取决于运行时向量长度。不能假定`std::vector`满足64字节对齐。
本教程使用未对齐访问或SVE正常加载，单独处理尾部。

不要在初学阶段使用`-ffast-math`；它可能改变NaN、无穷值和浮点比较语义。
保留标量参考实现，并区分“标量源码”和“编译器已经自动向量化的机器码”。
